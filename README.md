# L'aventure magique dont tu es la sorcière !

Prototype jouable (navigateur, PC / tablette / téléphone) du jeu d'aventure en 3D d'après le livre « L'aventure magique
dont tu es la sorcière ! ». Ce dépôt ne contient que la version construite du jeu, publiée sur GitHub Pages.

Jouer : https://hippyyohippyyay.github.io/petite-sorciere/

Crédits audio : voir CREDITS_AUDIO.md. Moteur : three.js (MIT), three-mesh-bvh (MIT), postprocessing (Zlib), n8ao (ISC);
polices Andika, Grandstander, Nunito, Caveat (SIL OFL).
